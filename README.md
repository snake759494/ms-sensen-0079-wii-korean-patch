## 게임 소개 및 대상 버전

『기동전사 건담 MS전선 0079』는 반다이 남코 게임스가 2007년 7월 26일 일본에서 발매한 Wii용 3D 슈팅 게임입니다(개발 BEC). 『기동전사 건담』 1년 전쟁의 지상전을 무대로, 콕핏 시점에서 Wii 리모컨으로 조준하고 눈차크로 모빌슈트를 움직입니다. 연방군·지온군 양쪽의 오리지널 스토리 모드, 원작 장면을 재현하는 에이스 파일럿 모드, 서바이벌·대전 모드 등이 들어 있습니다.

이 패치는 **일본판 R79JAF**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 맞는지가 중요합니다.

## 패치 적용 방법

### 1. RVZ·WBFS·WIA를 ISO로 바꾸기

xdelta는 **압축하지 않은 ISO**에만 적용됩니다. 원본이 RVZ 등 압축 형식이면 먼저 Dolphin에서 ISO로 바꿉니다.

1. Dolphin 게임 목록에서 게임을 우클릭하고 **파일 변환**을 고릅니다.
2. 형식을 **ISO**로 정하고 변환합니다. 이때 "쓰레기 데이터 제거"는 끄세요. 켜면 해시가 달라집니다.

명령줄에서는 다음과 같이 합니다.

```powershell
.\DolphinTool.exe convert -i '.\Kidou Senshi Gundam - MS Sensen 0079 (Japan).rvz' -o '.\Kidou Senshi Gundam - MS Sensen 0079 (Japan).iso' -f iso
```

### 2. 해시 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Kidou Senshi Gundam - MS Sensen 0079 (Japan).iso'
```

위 표와 다르면 적용을 중단하세요.

### 3. xdelta UI로 적용

1. 릴리즈에서 `MS_Sensen_0079_Wii_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Kidou Senshi Gundam - MS Sensen 0079 (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄로 적용

```powershell
.\xdelta3.exe -d -s '.\Kidou Senshi Gundam - MS Sensen 0079 (Japan).iso' '.\MS_Sensen_0079_Wii_KO_v1.0.xdelta' '.\Kidou Senshi Gundam - MS Sensen 0079 (Korean).iso'
```

결과 ISO는 Dolphin에서 그대로 실행하거나, 원하면 다시 RVZ로 변환해 보관해도 됩니다.

**세이브**
- 게임 ID는 원본과 같으므로 Wii 세이브 데이터는 원본판과 함께 쓸 수 있습니다.
- 원본판에서 만든 세이브 스테이트는 쓰지 마세요.

## 한글화 범위

- **화면 문자열(XBF·lua):** 모드 선택·파일 선택 설명, 프롤로그, 브리핑, 캐릭터 대화, 출격 준비 메뉴, MS 행거·세팅(기체·무기·성능 표시), 파일럿 이름, 미션 결과, 옵션, 에이스 파일럿·서바이벌·대전 모드 안내 등 2,061개 전체
- **튜토리얼 문장(`event/**/*.gev`):** 튜토리얼 안내 64개. 이 문장은 Wii 본체의 일본어 시스템 글꼴로 그려지므로, 실행 파일(`main.dol`)에 한글 317자 글리프를 넣고 쓰지 않는 한자 코드에 대응시켜 표시합니다.
- **그림 글자:**
  - 미션 시작 화면의 제목 68종(서울한강체)
  - 전투 화면의 격투 가능·사정거리 밖·보급 가능, 교환 가능·교환 불가·보급 중
  - 튜토리얼·2P 일시정지 메뉴(튜토리얼 그만두기·다음으로·다시 듣기·뒤로·결정), 선택 불가 표시, 대화 장면 이름표
- **원문 유지:** 타이틀 로고, 영어로 된 화면 제목·메뉴 항목(MODE SELECT·STORY·MS HANGAR·START MISSION 등)과 전투 HUD 영어 표기, 음성, 동영상, 저작권 표기, Wii HOME 메뉴

## 알려진 한계

**표기**
- 그림 글자는 원래 칸 크기에 맞추느라 일부 글자 폭을 줄였습니다.
- 게임 글꼴에 `·`(가운뎃점)이 없어 `・`로 적었습니다.

**확인 범위**
- Dolphin에서 직접 플레이하며 확인한 화면은 다음과 같습니다.
  - 타이틀, 모드 선택, 파일 선택, 연방군 스토리 프롤로그·브리핑·대화, 출격 준비 메뉴, MS 행거·세팅
  - 스토리 미션 1(시애틀) 시작 제목과 전투 화면(격투 가능·사정거리 밖 표시)
  - 튜토리얼 안내 문장과 튜토리얼 일시정지 메뉴
- 전투 중 「보급 가능」 표시는 수정 후 그림 파일로만 확인했습니다. 교환 가능/불가, 지온군 스토리 후반, 엔딩은 게임 화면에서 보지 못했습니다.
- 실기 Wii에서의 동작은 확인하지 못했습니다. 결과 ISO는 가짜 서명이므로 실기에서는 USB 로더 등 서명 검사를 하지 않는 환경이 필요합니다.
