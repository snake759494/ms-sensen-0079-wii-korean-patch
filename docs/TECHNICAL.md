# 기술 설명

일본판 R79JAF 디스크를 해석한 내용입니다. 경로는 데이터 파티션의 `files/` 기준입니다.

## 고친 파일

| 대상 | 내용 | 처리 |
| --- | --- | --- |
| `_2d/**/*.arc` 안의 `*.xbf` | 메뉴·설명문·브리핑·대화·결과 등 화면 문자열 (UTF-8) | `build.py` |
| `_2d/**/*.arc` 안의 `*.lua` | 기체·무기·파일럿 이름 등 스크립트 문자열 (UTF-8) | `build.py` (`luastr.py`) |
| `NORMAL_FONT.brfnt`, `IN_GAME_FONT.brfnt` (여러 사본) | 게임 글꼴 | `mkfont.py` |
| `event/**/*.gev` | 튜토리얼 안내 문장 (Shift-JIS) | `gev.py`, `kgev.py` |
| `sys/main.dol` | 튜토리얼 문장용 한글 글리프와 후킹 코드 | `kgev.py` |
| `*.brres` 안의 TEX0 | 미션 제목, 전투 표시, 튜토리얼 일시정지 메뉴, 이름표 등 그림 글자 | `texpatch.py`, `tex.py` |

## U8 아카이브

- `U\xaa8-` 헤더의 Wii 표준 아카이브입니다. 아카이브 안에 아카이브가 여러 단계로 들어 있어 `build.py`가 재귀적으로 풀고 다시 묶습니다.
- `u8.py`가 파싱과 재구성을 합니다. 파일 크기가 바뀌므로 아카이브는 다시 정렬해 만듭니다.

## XBF (바이너리 XML)

- `XBF\0` 헤더 뒤에 태그·속성 구조와 문자열 테이블이 있습니다. 값 문자열 테이블이 파일 끝에 있어 문자열 길이를 자유롭게 바꿀 수 있습니다.
- `xbf.py`가 파싱과 재구성을 합니다. 번역은 원문 문자열 단위로 대응합니다.

## 게임 글꼴 (BRFNT)

- 20×21 셀의 I4 글꼴이며 코드는 UTF-8입니다.
- 게임 안에서 쓰지 않는 한자 슬롯을 회수해 번역문에 쓰인 한글 869자를 넣었습니다. 글꼴 크기와 시트 수가 바뀌지 않습니다.
- 글자는 나눔스퀘어네오 ExtraBold 19px을 4배로 그린 뒤 줄여 안티앨리어싱했습니다.
- `·`(U+00B7)는 글꼴에 없으므로 번역문에서는 `・`를 씁니다.

## 튜토리얼 문장 (GEV + 시스템 글꼴)

- `$EVF` 파일: 0x10에 문자열 수, 0x14에 오프셋 표 위치, 0x18에 문자열 풀 위치가 있습니다. 오프셋은 4바이트 단위 u16입니다. `gev.py`는 106개 파일 모두 바이트 단위로 같게 다시 만들 수 있습니다.
- 튜토리얼 문장은 Wii 본체 ROM의 Shift-JIS 시스템 글꼴(OSInitFont 이후 I4로 펼친 것)로 그려지므로, 게임 글꼴만 바꿔서는 한글이 나오지 않습니다.
- 그래서 한글 317자를 쓰지 않는 Shift-JIS 1수준 한자 코드에 대응시키고, 문장을 그 코드로 인코딩했습니다.
- `main.dol`에 섹션을 하나 더해(0x80467920) 후킹 코드와 24×24 I4 한글 글리프 317자를 넣었습니다.
  - OSInitFont 끝의 `li r3,1`(0x80334750)을 분기로 바꿔, 펼쳐진 시스템 글꼴의 해당 한자 자리에 한글 글리프를 덮어쓴 뒤 0x80334754로 돌아갑니다.
  - 섹션이 차지하는 만큼 ArenaLo 상수(0x8032e8d4, 0x8032e924)를 0x8047e400으로 올렸습니다.

## 그림 글자 (TEX0)

- `tex.py`가 I4·I8·IA4·IA8·RGB565·RGB5A3·RGBA8·CMPR을 디코드·인코드합니다. 크기와 형식을 그대로 두고 픽셀만 바꿉니다. 밉맵이 있으면 함께 다시 만듭니다.
- `texpatch.py`가 텍스처 이름별로 글자 영역을 지우고 한글을 그립니다.
  - `ME01_TELOP` (각 `TELOP_xxxx` 아카이브): 미션 시작 제목 68종, 서울한강체 EB. 미션 코드별 번역은 `text/telop_ko.txt`
  - `EF_Indicator00`, `ZE_Indicator00`, `EF_Indicator05`: 전투 화면의 격투 가능·사정거리 밖·보급 가능·교환 가능/불가·보급 중
    - `EF_Indicator00`의 보급 가능 띠는 게임이 반시계 방향 90°로 돌려 그리므로, 가로로 그린 글자를 시계 방향으로 돌려 넣습니다.
  - `Tutorial_00`, `2P_PAUSE`: 튜토리얼·2P 일시정지 메뉴
  - `SAL01`: 선택 불가 표시, `CHAT_name1/2`: 대화 이름표, `GSH_MSG_Window_01`: 메시지 창 이름표

## 디스크 이미지 만들기

- 배포 xdelta를 작게 하려고 원본 디스크의 파일 배치를 유지합니다. `wit`로 다시 만든 ISO는 배치가 달라 데이터 파티션 전체가 바뀝니다.
- `inject.py`: 복호화 이미지(`wit --enc decrypt --psel whole`)의 데이터 영역(클러스터 0x8000 중 데이터 0x7C00)에 직접 씁니다. 커진 파일 2개와 `main.dol`은 원본 앞쪽의 큰 빈 구간에 2MB 그룹 단위로 정렬해 옮겼습니다.
- `rehash`: 클러스터 머리의 H0(0x400 블록 31개), H1(서브그룹 8클러스터), H2(그룹 8서브그룹)와 H3 표를 다시 계산합니다. 마지막 그룹은 52클러스터뿐이며, 없는 클러스터 자리는 0으로 채웁니다.
- `restore`: 새 배치에서 아무 파일도 쓰지 않는 그룹은 원본 암호화 데이터와 원본 H3 값으로 되돌립니다.
- `fixtmd`: TMD의 콘텐츠 해시(H3 표의 SHA-1)를 고치고 서명을 0으로 채운 뒤 예약 영역 4바이트를 바꿔 가며 SHA-1 첫 바이트가 0이 되게 합니다(가짜 서명).
